# 쿠팡파트너스 오늘의 핫딜 수집기 (1단계: 수집 + DB 축적)

## 설치 (Termux)

```bash
cd coupang-hotdeal
npm install
```

## 설정

`config.js` 파일을 열어서:

1. `ACCESS_KEY`, `SECRET_KEY` — 파트너스 사이트(partners.coupang.com) > Tools > 파트너스 API 에서 발급받은 값으로 교체
2. `CATEGORIES` — 추적하고 싶은 생필품 카테고리의 ID로 교체
   - 정확한 카테고리 ID는 파트너스 API 가이드의 "문서" 탭에서 베스트카테고리 조회 API 설명을 보면 카테고리 목록/ID가 나와 있을 거예요. 그 표 내용을 캡처해서 주시면 바로 채워드릴 수 있어요.

## 실행

```bash
npm start
```

실행하면:
1. 설정된 카테고리의 상품을 조회
2. 상품명에서 포장 단위(롤/매/개/kg 등)를 파싱해서 단위가격 계산
3. `data/hotdeal-db.json`에 오늘 날짜로 스냅샷 저장 (기존 기록 위에 누적)
4. 평균가 대비 할인율 기준으로 상위 5개 후보를 콘솔에 출력

## 아직 안 된 것 / 다음 단계

- **실제 API 응답 필드명 확인 필요**: `index.js`의 `p.productId`, `p.productName`, `p.productPrice`, `p.productUrl` 부분은 실제 쿠팡 API가 내려주는 필드명과 다를 수 있습니다. 한 번 실행해서 콘솔에 원본 응답(`result`)을 찍어보고 필드명 맞춰야 해요.
- **카테고리 ID 미확정**: `config.js`의 `CATEGORY_ID_HERE`를 실제 값으로 교체해야 동작합니다.
- **딥링크 변환**: 지금은 `productUrl`을 그대로 쓰는데, 실제 콘텐츠에 넣을 땐 `coupangClient.createDeeplink()`로 파트너스 추적 링크로 바꿔야 커미션이 잡힙니다.
- **09시/21시 자동 실행**: 기존 파이프라인의 스케줄러(cron 등)에 `npm start` 또는 이 로직을 모듈로 불러와서 연결하면 됩니다.
- **쇼츠 제작 연동**: 이 스크립트는 "오늘의 핫딜 후보 데이터"까지만 만듭니다. 이 결과를 기존 PLANNER/CREATE 파이프라인에 넘겨서 대본/영상 제작하는 연결부는 별도 작업 필요합니다.

## 호출 제한 주의

쿠팡파트너스 검색 API는 시간당 호출 횟수 제한이 있고, 초과 시 계정 자체가 API 사용 제한(길게는 영구)될 수 있습니다. 그래서 이 스크립트는 넓은 검색이 아니라 **미리 정해둔 카테고리 소수 개**만 하루 2번(09시/21시) 조회하는 걸 전제로 설계했습니다. 카테고리를 너무 많이 추가하거나 실행 빈도를 늘리지 마세요.
